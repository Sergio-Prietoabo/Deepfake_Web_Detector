# Deepfake Ensemble

This repository combines three state-of-the-art deepfake detection models:

| Model | Repository |
|---------|------------|
| Video-MAE | https://huggingface.co/Hemgg/deepfake_model_Video-MAE-1 |
| Deep Fake Detection | https://huggingface.co/Naman712/Deep-fake-detection |
| CViT Deepfake Detection | https://huggingface.co/mhamza-007/cvit_deepfake_detection |

> **Note**
>
> The pretrained weights are not included in this repository because their size exceeds GitHub's storage limits.
>
> To reproduce the results, download the model weights from the original Hugging Face repositories and place them in the appropriate directory.
